# Privacy Policy for Grey Black White

**Last updated:** November 9, 2026

Grey Black White is a theme extension for Microsoft Edge. It does not collect, use, store, or share any personal information.

The extension contains no scripts, makes no network requests, and requests no browser permissions. It only supplies static color values to the Microsoft Edge theme system. Microsoft Edge may store the selected theme locally as part of normal browser operation; that data is controlled by Microsoft Edge and is not accessed by this extension.

Because the extension collects no data, there is no data to access, correct, delete, or transfer.
