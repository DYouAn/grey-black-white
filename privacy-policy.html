GREY BLACK WHITE

Privacy Policy

Last updated: November 9, 2026

Grey Black White is a theme extension for Microsoft Edge. It does not collect, use, store, or share any personal information.

What the extension does

The extension only supplies static color values to the Microsoft Edge theme system. It has no scripts, no content scripts, no network requests, and requests no browser permissions.

Data collection

No user data is collected, transmitted, sold, or shared. No analytics are used. There is no data to access, correct, delete, or transfer.

Local browser data

Microsoft Edge may store the selected theme locally as part of normal browser operation. That data is controlled by Microsoft Edge and is not accessed by this extension.
